# 🧭 Pokemon Data Explorer

A responsive and interactive React application that fetches and displays the first 150 Pokémon using the [PokeAPI](https://pokeapi.co/). Users can search by name and filter Pokémon by type. It also supports light/dark mode toggle.

## 🚀 Features

- 🔍 **Real-time search** by Pokémon name
- 🎯 **Type-based filtering** via dropdown
- 🖼️ **Pokémon cards** with Name, Image, Type(s), and ID
- 💡 **Light/Dark theme** toggle with local storage persistence
- 🧱 **Responsive UI** for mobile and desktop
- 💬 **Loading shimmer effect**
- ⚠️ **Error handling and retry option**
- ♻️ **Reusable component structure**

## 📦 Technologies Used

- **React JS** with Hooks
- **CSS Modules** for styling
- **React Router** (for error handling and future extensibility)
- **PokeAPI** for fetching Pokemon data
- **LocalStorage** for persisting theme
- **Parcel** is used as a bundler

## 🛠️ Getting Started

Follow these steps to run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/https://github.com/Himanshu4922/Pokemon-Explorer.git

cd Pokemon-Explorer

```
### 2. Install dependencies
```bash
npm install
```
### 3. Start the development server
```bash
npm Start
```
